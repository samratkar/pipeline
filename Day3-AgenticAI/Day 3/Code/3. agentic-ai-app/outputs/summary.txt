This paper proposes Semantic SPA, a framework designed to solve the Student-Project Allocation (SPA) problem in modern, globalized educational settings by leveraging Web 3.0 semantic technologies. The core motivation is that traditional SPA approaches, often built as standalone applications, struggle with interoperability as universities and campuses increasingly collaborate across disciplines, institutions, and geographic boundaries. The authors argue that standardizing SPA data elements semantically and exposing them as interoperable services can enable flexible, cross-institutional, situational project allocations.

The proposed framework has three main components. First, it introduces an OWL-based SPA ontology that standardizes the concepts and relationships involved in SPA (students, projects, supervision capacity, and related constraints), providing a formal, shared semantic model to bridge heterogeneous institutional data. Second, it deploys SOAP-based Web services that implement SPA logic, enabling institutions to publish, discover, and consume SPA capabilities in a unified manner. Third, the framework adopts OWL-S to enable automatic discovery, composition, and invocation of these Web services by educational institutions or semantic agents, supporting situational SPA scenarios where collaboration may span multiple campuses or universities.

A key aspect of the framework is its focus on semantic interoperability to address the interoperability challenges brought by globalization. By leveraging existing semantic investments within institutions (e.g., data converted to semantic formats and exposed as Linked Open Data), the Semantic SPA framework aims to facilitate cross-institution, cross-campus, and cross-disciplinary project allocations. The authors position the SPA ontology as a reference model that standardizes SPA concepts, while the OWL-S approach enables dynamic, service-oriented integration and orchestration of SPA processes across organizational boundaries.

Overall, the paper articulates a cohesive architecture for semantic SPA that (i) standardizes data elements through an ontology, (ii) implements practical service interfaces, and (iii) enables automated service discovery and composition for situational, interoperable SPA in modern higher education.
